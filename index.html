⭐ Flagship Full-Stack Application

Catering & Event Commerce Platform

An end-to-end event catering service platform built for high-touch customer ordering and operational management. Features a customer-facing responsive Next.js frontend, an atomic Django REST Framework backend with serverless PostgreSQL, and an automated event notification pipeline routing inquiries directly to staff Telegram chats.

🌐 Launch Web App Demo ↗ ⚡ Browse Live REST API (JSON) ↗ ⚙️ Django Admin Workspace ↗
🔔
Telegram Notifications

Asynchronous event dispatching system keeping operations teams instantly notified of incoming customer submissions.

  • Non-blocking background delivery: Workers process notifications asynchronously without lagging client response times.
  • Dynamic lead-time calculations: Formats dates with relative urgency flags (e.g., "in 3 days", "today").
  • Automated phone resolution: Matches incoming customer phone numbers with Telegram user profiles.
  • Dedicated subscriber bot: Telethon/polling worker managing staff subscriptions.
🛠️
Custom Django Admin

Bespoke administrative dashboard tailored specifically for managers to streamline order fulfillment.

  • 1-Click Telegram dispatch: Native custom action button in order views to re-dispatch notifications on demand.
  • Visual order line items: Inline dish thumbnails and preview photos embedded directly in the order table.
  • Subscriber management: Full CRUD interfaces for managing Telegram channel bindings and email recipients.
  • Health diagnostics: Integrated SMTP checks and database connection monitoring.
🚀
CI/CD & Architecture

Production-grade deployment pipelines with automated validation gates and cloud scalability.

  • Automated GitHub Actions: Comprehensive linters and test suites validating changes on every commit.
  • Dual Vercel pipelines: Independent SSR Next.js frontend and Serverless WSGI backend builds.
  • Serverless PostgreSQL: Neon cloud database with connection pooling and SSL encryption.
  • Docker environment: Multi-container Docker Compose configuration for unified local development.
