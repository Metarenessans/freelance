Flagship System

Catering & Event Commerce Platform

Next.js 14 Django REST PostgreSQL (Neon) Telegram Engine Docker GitHub Actions

A production-ready e-commerce platform for event catering. Built with an isolated public sandbox allowing clients to place real cart orders, inspect server-side price validation, and observe automated operational routing into Telegram and Django administration.

Interactive Sandbox: Launch Web App ↗ Live REST API (JSON) ↗ Django Admin Panel ↗

Telegram Notification Engine

Non-blocking asynchronous messaging system keeping operations staff notified in real-time.

  • Async Dispatch: Notifications run in background threads without delaying customer HTTP responses.
  • Lead-Time Urgency: Automatically parses event dates with relative flags (e.g., in 3 days, today).
  • Phone Resolution: Formats contact numbers and resolves Telegram usernames for instant staff outreach.
  • Subscriber Bot: Dedicated Telethon worker for manager channel subscriptions.

Custom Django Administration

Bespoke administrative dashboard tailored specifically for managers to streamline order fulfillment.

  • 1-Click Dispatch: Custom action button in order views to re-trigger Telegram alerts on demand.
  • Visual Dish Previews: Inline dish thumbnails embedded directly inside order item tables.
  • Subscriber CRUD: Dedicated interfaces for managing Telegram channels and Email alert lists.
  • Diagnostic Checks: Integrated SMTP health views and connection validation.

Architecture & CI/CD

Engineered for high availability, transactional consistency, and automated delivery.

  • Dual Vercel Deploy: Independent SSR Next.js frontend and Serverless WSGI backend builds.
  • Cloud PostgreSQL: Neon serverless database with connection pooling and SSL encryption.
  • Price Protection: Server calculates prices from catalog models; clients cannot tamper with totals.
  • Automated Testing: GitHub Actions pipeline verifying linting and test suites on push.
