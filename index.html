Asynchronous Telegram Alert Pipeline

When a customer places an order or requests an event quote, the Django backend asynchronously formats and routes an urgent dispatch into staff Telegram channels without blocking HTTP execution.

  • Non-blocking workers: Uses background thread dispatchers so API response latency stays under 50ms.
  • Lead-time urgency calculations: Computes days remaining until the banquet (e.g. in 3 days, today).
  • Phone number resolution: Normalizes contact numbers and resolves Telegram user handles for managers.
  • Standalone subscriber worker: Telethon worker allowing staff to subscribe or mute notification channels.
